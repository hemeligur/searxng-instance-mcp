# Project Brief

## Nome do Projeto
**searxng-instance-mcp**

## Tipo
MCP Server (Model Context Protocol) - Python com uv

## Descrição Resumida
Servidor MCP que encapsula busca na web usando instâncias SearXNG, com rotação automática e transparente entre instâncias para garantir alta disponibilidade.

## Propósito
- Prover ferramenta `web_search` para agentes de IA
- Esconder complexidade de múltiplas instâncias SearXNG do cliente
- Garantir resiliência através de fallback automático

## Stack Principal
- Python 3.10+
- uv (gerenciador de pacotes)
- MCP SDK
- httpx (cliente HTTP assíncrono)
- tenacity (retry logic)
